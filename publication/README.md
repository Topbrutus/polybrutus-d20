# Polybrutus D20 — Controlled release checklist

This is a reproducible mathematical preprint with substantial AI use disclosed, no claim of new physical spacetime dimension, experimental frequency or novel universal theorem.

1. Verify `src/verify_d20.py` and `tests/independent_d20.py` locally on identical certificate.
2. Create the GitHub repository **privately**, verify both tests succeed in GitHub Actions on the candidate commit.
3. Freeze the successful commit with immutable annotated tag `v0.1.0`.
4. Archive the Git tag with `git archive v0.1.0`; hash the ZIP, PDF and 300-pair JSON with SHA-256.
5. Stage or reuse **one** authorized Zenodo direct-REST draft. Confirm author, CC BY 4.0 text license, parent D19 DOI, exact tagged code source, clear AI disclosure and remote attachment checksums.
6. Make GitHub public, verify tag commit through public API, publish the same Zenodo draft and confirm public DOI and three file checksums.
7. Add verified DOI to README, CITATION.cff, release_manifest.json and central Memoria; do not change scientific tag.

Do not create duplicate Zenodo deposits through simultaneous auto-harvesting. Never include secrets or private files in public Git.
